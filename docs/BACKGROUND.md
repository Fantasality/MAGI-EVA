# MAGI SYSTEM — 背景考

> 本文记录 MAGI-EVA 这款应用所依据的正典设定、它复刻的决策机制，以及本项目相对原典与前作所做的一处结构性改动。凡属动画设定者称「设定」，凡属本作实现者称「实现」，二者在文中分开陈述。

---

## 一、正典设定

MAGI（マギ）是《新世纪福音战士》中设置于 NERV 本部的超级计算机集群，也是整个组织几乎所有重大决断的裁决者。它的名字取自《马太福音》中循星而来、朝拜新生耶稣的**東方三博士（Magi）**——三位来客各自带来不同的礼物与视角，正如这台机器由三份各自独立的人格构成。

MAGI 由**赤木直子博士**完成。她把自己的人格分割为三个片段，分别移植进三台子系统，使三者在同一问题上以完全不同的价值观各自作答、再行合议。三台子系统与它们承载的人格是：

| 子系统 | 编号 | 承载的人格 | 判断的立足点 |
| --- | --- | --- | --- |
| **MELCHIOR** | • 1 | 赤木直子身为**科学家**的人格 | 证据、逻辑、可验证的事实；不为感情、忠诚或希望所动 |
| **BALTHASAR** | • 2 | 身为**母亲**的人格 | 保护孩子、维持人所倚赖之物的完整；宁可承担短期代价也要阻止长久伤害 |
| **CASPER** | • 3 | 身为**女性**的人格 | 爱、梦与欲望；以是否忠于内心与自我为尺度，把欲望、尊严与情感的诚实置于冷静的效用之上 |

正典中 MAGI 的两次关键出场，确立了它在剧情里的分量：

- **第十一使徒之战**：使徒以信息入侵的方式试图从内部瓦解 MAGI，CASPER • 3 将其击退，保住了系统。
- **《The End of Evangelion》**：NERV 本部濒临自毁之时，MAGI 以**一票否决**的机制驳回了自毁指令——即便身在其中的操作者希望它执行。

此外，正典提示 MAGI 并非孤例：世界各地建有**复制型号**，包括松代二号（Matsushiro No.2）、柏林、汉堡、马萨诸塞与北京。它们共享同一套三贤人合议的架构，只是人格移植的细节与用途各有分工。

直子博士在这套系统完成之后，于中央教条区（Central Dogma）结束了自己的生命；此后 MAGI 由她的女儿**赤木律子博士**继续维护。

> **传说/设定**：关于拟人化程度、算力规模与复制型号之间的差异，动画本身着墨有限，以上均以剧情明示者为准。

## 二、MAGI 的决策机制

正典里 MAGI 的运作方式，可以概括为两句话：**三贤人各自独立作答，再以「一票否决」合议**。

- **三贤人合议**：同一个询问被同时交给 MELCHIOR、BALTHASAR、CASPER。三者**互不协商、互不看对方的答案**——它们不是讨论后收敛，而是各自以本身的人格给出结论，再由系统汇总。
- **一票否决制**：只要有一位贤人反对，整体结论即为否决。三票不是「少数服从多数」，而是「全体一致方可放行」。

本作把这一机制严格映射为五种会在控制台上打印的结论，并且**规定了不可调换的优先级**。判定顺序如下（与 `core/MagiLogic.java:vote` 及参考实现 `main.py:response_status` 逐条对应）：

| 次序 | 结论 | 触发条件 |
| --- | --- | --- |
| 1 | **誤差** | 有贤人未能给出结果（调用失败、无裁决） |
| 2 | **情報** | 该询问不属于 yes/no 类 |
| 3 | **拒絶** | 至少有一位贤人反对（一票否决） |
| 4 | **状態** | 至少有一位贤人**附条件**同意 |
| 5 | **合意** | 三贤人**一致无条件**同意 |

顺序本身就是这套机器的行为契约，理由如下：

- **誤差最高**：一份掺进了失败读数的合议结果不可采信。只要有一台子系统没交出答案，结论就必须是「误差」，而不是拿剩下两票硬凑一个判断。
- **情報先于否决**：若询问本身不是一个可否决的事项（例如「为什么」「请描述」「给个数」），MAGI 根本没有立场去同意或否决，它只能提供情报。**一个非 yes/no 的询问，永远不可能得到「合意」**——因为「合意」的前提是这台机器有资格表决，而它没有。
- **拒絶先于状態**：否决的强度高于附条件。一位贤人坚决反对，就已足够压过另一位贤人的有条件同意。
- **状態先于合意**：只有当三位贤人都无条件接受，才升格为「合意」。任何一处保留意见，结论就停在「状態」。

作为对照，参考实现与脚本在非 yes/no 且无错误时，会**跳过投票直接给出情报**（`tools/smoke_test.py:331-334`）；这与上表的优先级是同一套规则的两种写法。

## 三、移植到语言模型

最早的 MAGI 移植（本项目视觉与逻辑上的参考实现 [TomaszRewak/MAGI](https://github.com/TomaszRewak/MAGI)）把三贤人做成三次独立的大模型对话。每个子系统收到同一段人格提示与同一个问题，用一段**自然语言散文**作答——「我认为应当……」或「我无法同意……」。

系统要得到可投票的结论，就必须在模型输出之后补上第二道工序：**把这段散文归类回 `yes`／`no`／`conditional`**。于是流程变成：

```
询问 ──▶ 一次模型对话（作答，散文） ──▶ 归类器 ──▶ yes / no / conditional ──▶ 合议
```

这套两段式设计（**作答 → 归类**）有一处根上的损耗：**归类发生在模型之外**。模型真正「想到」的是一个连续的、带权重的倾向，而输出只有一段文字；归类器再去猜这段文字落在哪个格子里。中间那一步是有损的——

- 归类的依据是措辞，不是概率。模型说「原则上可以，但……」时，到底是 `conditional` 还是 `yes`，由归类器的规则决定，而非由模型决定。
- 「有多确定」这个信息在散文里几乎不可靠地表达，归类之后更是无从还原。
- 归类器本身也会错，而它的错误不会被任何一票的分数显式记录，只会悄悄改变合议结果。

换言之，参考实现里三贤人的「意见」，其实是**对模型散文的一次再解释**，而不是模型自己的判断。

## 四、本作的改动

本作不再让模型写散文、也不再事后归类。三个子系统改由**决策模型 Jev** 驱动：Jev 接受 `choice`／`noul`／`score` 三类结构化提问，**在一次往返里**直接返回：

- `choice` —— 最终选择，**外加完整概率分布**（`MagiModels.Choice.probabilities`）；
- `score` —— 0–9 的确定性打分，**外加该项打分的置信度与分档判据**（`MagiModels.Score`）；
- `noul` —— 布尔判定的真/假概率（用于闸门）；
- 以及 `usage` —— 输入/输出 token 与美元成本（`MagiModels.Usage`）。

这样做的结构性收益是：**「作答 → 归类」这一步整个消失了**。模型被要求直接输出一个自洽的选择，连同它的概率与确信度；客户端只负责**搬运**这些数字，不再对模型的措辞做任何再解释（见 `MagiModels` 类注：「只搬运模型直接给出的数据」）。于是：

- 三贤人的「意见」就是模型给出的选择本身，不再是散文的二次归类；
- 机器打印的是**模型自己的数字**——真实概率、真实置信度、真实确信分档；
- 成本与延迟也不再是黑箱：Jev 直接回报 token 与费用，这是订阅式对话接口不会告诉你的东西。

结果是，MAGI 的合议第一次建立在**可观测、可复核的量化读数**之上，而不是建立在三次散文解读之上。

## 五、一份真实的合议记录

以下是一次针对活体 Jev 接口的真实冒烟测试记录（`tools/smoke_test.py`），询问为：

> **「我们应该启动人类补完计划吗？」**

**闸门 GATE**（1427 ms）：`is_yes_no = true @ 0.96`，`is_decision = true @ 0.97`。这一询问被判定为可否决事项，故进入表决。

| 子系统 | 裁决 | 置信度 | 确信度 | 概率分布 | 延迟 |
| --- | --- | --- | --- | --- | --- |
| **MELCHIOR • 1** | `conditional` | 0.45 | 2.27 | `conditional 0.64 / yes 0 / no 0.36` | 1582 ms |
| **BALTHASAR • 2** | `no` | 0.77 | 5.56 | `conditional 0.15 / yes 0 / no 0.85` | 1103 ms |
| **CASPER • 3** | `no` | 0.52 | 3.50 | `no 0.68 / conditional 0.31 / yes 0.01` | 1232 ms |

**合议**：`conditional | no | no` → **拒絶（NO）**。
成本 `$0.000172`，总延迟 `5344 ms`。

**读法**：这一次合议恰好把三份人格的分歧摆到了台面上。身为**科学家**的 MELCHIOR 不愿无条件放行，却也不想彻底否定，于是停在 `conditional`——但它的置信度只有 0.45、确信度只有 2.27，两项都是三贤人中最低，说明这个「有条件的同意」本身并不牢靠。身为**母亲**的 BALTHASAR 给出了最坚决的反对：0.77 的置信度、5.56 的确信度，`no` 的概率 0.85。身为**女性**的 CASPER 同样反对，但姿态不同——0.68 的 `no` 之上还压着 0.31 的 `conditional`，是一份犹疑的拒绝。

三票为「一票否决」的前提正好成立：BALTHASAR 的 `no` 与 CASPER 的 `no` 使整体结论落在**拒絶**，MELCHIOR 的附条件同意无法翻盘。值得注意的是——三贤人**确实各说各话**：同一个人格碎片的三个侧面，对同一个问题给出了三种不同的措辞与三种不同的强度。这正是 MAGI 之所以是 MAGI 的地方，也是本作让模型自己报出概率、而不再事后归类之后，第一次可以被**直接读数**的东西。
